Ephinea Font Setup
==================

[Ephinea Phantasy Star Online: Blue Burst](https://ephinea.pioneer2.net){:target="_blank"} uses **Tahoma** as the default in-game font, but also includes two additional fonts: **Dotum** and **Gulim**. These can be used to make the in-game text more closely match the original GameCube release. However, they need to be installed manually on your OS before selecting them in the launcher. This guide shows you where to find the fonts and how to install them on both Windows and Steam Deck.

Windows
-------

1. Navigate to your PSO installation’s `font` folder (e.g. `C:\Users\Username\EphineaPSO\font`).
2. Right-click `GULIM.TTC` → **Install**.
3. Select the font in the Ephinea Launcher (**Options** → **More** → **Font**).
4. Click **Save**, then start the game.

---

Steam Deck
----------

1. Navigate to your PSO installation’s `font` folder (e.g. `/home/deck/.local/share/Steam/steamapps/compatdata/3535824940/pfx/drive_c/EphineaPSO/font`).
2. Right-click `GULIM.TTC` → **Copy**.
3. Navigate to the prefix’s `Fonts` folder (e.g. `/home/deck/.local/share/Steam/steamapps/compatdata/3535824940/pfx/drive_c/Windows/Fonts`).
4. Right-click → **Paste**.
5. Select the font in the Ephinea Launcher (**Options** → **More** → **Font**).
6. Click **Save**, then start the game.

FAQs
----

### You said there are two fonts, but I only see one file?

Correct - both fonts are included in the same file. In fact, there are four fonts: two standard and two monospace variants (suffixed "Che").

### Which font is best?

It’s up to you - I prefer **Dotum**.
